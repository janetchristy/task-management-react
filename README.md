# Task Manager React App

This is a simple **Task Management** application built with **React** and **Vite**.  
It demonstrates **React Router, Forms, Table management, CRUD operations, and local storage**.

---

## **Features**

- **Home Page**: View all tasks in a table with search functionality.  
- **Create Task**: Add new tasks with title, description, and status.  
- **Edit Task**: Update existing tasks.  
- **Delete Task**: Remove tasks from the list.  
- **Local Storage**: Tasks are saved in the browser so data persists.
